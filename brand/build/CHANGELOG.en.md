# Xhandy Changelog

All notable changes to the Xhandy brand kit. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

Versioning: `meta.version` in brand.yaml is a single counter, bumped when the owner approves a change; the download is named after it (`xhandy-brand-kit-v<version>.zip`). Each release is labelled by size:

- **major**: the name, the primary logo or the primary colour changes; anything that makes old assets wrong
- **minor**: new assets, tokens, templates or blocks; existing ones keep working
- **patch**: fixes: wording, file clean-ups, contrast tweaks with no visible change of identity

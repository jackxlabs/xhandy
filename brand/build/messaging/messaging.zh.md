### 30 秒 · 100 字

Xhandy 是给手动玩 X 的人用的浏览器插件，开源免费。刷 X 时，它在每条帖子旁边标出发了多久、每小时多少浏览，你和作者是否互关、互动过几次，一眼看出该回哪条；打字时还会提醒你别发重复回复。它不点击、不发送、不关注，数据只存在你的浏览器里。

### 2 分钟 · 390 字

靠手动回复起号的人，最费劲的是挑帖子：哪条正在火，一眼看不出来；和作者有没有互关、之前聊过几次，只能点进主页或者把鼠标移到头像上看。

Xhandy 是一个浏览器插件，支持 Chrome、Edge 和 Brave，把这些信息直接标在每条帖子旁边。作者名旁的小标签写着发了多久和每小时浏览量，例如「2小时 · 1.5万/时」：每小时 1000 以上变橙，1 万以上变红，超过 48 小时的帖子变灰。旁边是你们的关注关系（⇄ 互关、→ 我关注他、← 他关注我）和互动记录，例如「互动3次 · 今天」。

写回复时，如果和你最近发过的某条很像，Xhandy 会提醒你：重复的回复最容易被当成垃圾内容。页面底部的小条统计今天的点赞、回复、发帖、关注数和在线时长。按 Alt+U 打开「没回关我」列表，只能看，没有取关按钮；选中帖子按 Shift+F，焦点跳到作者的关注按钮上，按 Enter 的是你自己。

Xhandy 不点击、不输入、不发送、不点赞、不关注。它只申请「存储」和「无限存储」两个权限，不联网、不做统计、不加载远程代码，数据只在你的浏览器里，可以随时导出或清空。

Xhandy 开源免费，现在是 v0.4.7，从 GitHub 发布页下载：github.com/jackxlabs/xhandy。路线图上接下来是互动队列、灵感清单和导出，之后上架商店。

## FAQ

### 用户

**用 Xhandy 会不会被封号？**（草稿）

- 短答：Xhandy 不替你点击、发送或关注，关注和取关超过每日软上限会提醒你。没有哪个工具能保证账号不被限流。
- 详答：Xhandy 只读取页面和你自己的操作，不点击、不输入、不发送、不点赞、不关注，也不模拟鼠标事件，端到端测试会检查这一点。关注和取关默认每天超过 20 个会提醒（只提醒，不拦截），因为关注太快容易被限流；写回复时，和最近发过的很像也会提醒。账号会不会被限流最终由 X 决定，Xhandy 只能帮你避开最常见的问题。
- 来源：`readme` · 2026-10-20

**Xhandy 会收集我的数据吗？**（草稿）

- 短答：不会。它不联网、不做统计、不加载远程代码，数据只存在你的浏览器里。
- 详答：Xhandy 只申请「存储」和「无限存储」两个权限，只在 x.com 和 twitter.com 上运行。存在你浏览器里的有：设置、每日计数、每个作者的点赞和回复次数、关注关系，以及你最近 300 条回复和帖子的文字（用来提醒重复回复）。在设置页可以导出、导入或清空全部数据。完整隐私政策见仓库里的 PRIVACY.md。
- 来源：`readme` · 2026-10-20

**支持哪些浏览器？怎么安装？**（草稿）

- 短答：Chrome、Edge、Brave。从 GitHub 发布页下载压缩包，解压后在 chrome://extensions 打开开发者模式，加载已解压的扩展程序。
- 详答：到 github.com/jackxlabs/xhandy 的发布页下载 xhandy-版本号.zip，解压得到 xhandy 文件夹，把它放在以后不会动的位置。在 chrome://extensions 打开开发者模式，点「加载已解压的扩展程序」，选 xhandy 文件夹。更新时解压覆盖原文件夹，再点「重新加载」。不要换文件夹位置：扩展 ID 跟着路径走，换了位置原来的数据就读不到了。
- 来源：`readme` · 2026-10-20

**「没回关我」列表为什么不全？**（草稿）

- 短答：列表只用你刷 X 时已经加载过的数据。先打开自己的「正在关注」页面滚到底，再按 Alt+U。
- 详答：Xhandy 不额外联网，关系数据来自 X 在你浏览时已经发给浏览器的内容。想要完整名单，打开自己主页的「正在关注」页面一直滚到底，再按 Alt+U。如果你关注的人里一个回关的都没显示，列表会提示 X 可能改了数据，这时别信这份列表。

**能自动关注或自动回复吗？**（草稿）

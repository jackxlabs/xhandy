Product: browser extension with helpers for people who engage on X by hand. Never automates; shows hints
(post age and heat, interaction memory, follow relationship, duplicate-reply warnings, daily stats). Data stays in the browser.

Concepts (ranked): 1. mutual follow relationship (⇄)  2. post heat, interaction memory
Must include: X (the extension only lives on X), "handy" = convenient
Must avoid: anything that resembles the X Corp logo (straight thick + thin diagonals with a break). README states Xhandy is not affiliated with X Corp.
Palette: cyan #06b6d4 → violet #8b5cf6 → pink #ec4899, deep violet #4c1d95 (source: src/content.css `--xh-edge`, `--xh-num`)
Logo itself: mono (black / white); brand gradient goes on the icon tile and backgrounds
Style: organic / hand-drawn   Mood: sharp, energetic
Primary contexts: browser toolbar 16px (priority), Chrome Web Store 128px + promo images, X / GitHub avatar (circle crop), GitHub README / releases (lockup)
